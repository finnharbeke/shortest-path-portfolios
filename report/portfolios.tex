\section{Portfolios}
\label{sec:portfolios}

We propose to solve \textit{ref query pair path} with the \textit{portfolio method} framework. Given $\mathcal O(n^2)$ space, how can we compute portfolios of $k$ paths in polynomial time, such that for any graph weight realization and query $(s, t)$, the shortest path in the respective portfolio is close to the optimal shortest path from $s$ to $t$.
